image through Assests:-
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(title: const Text('Image.asset Example')),
        body: Center(
          child: Image.asset('assert/img.jpg'),
        ),
      ),
    );
  }
}

process for this image assets
 
project view->create directory(asserts) cut jpg image and convert into jpg while saving image and then copy to asserts directory which you created.
 
that must be in jpg (ex:-name it as like image.jpg)


->in pubspec.yaml 
flutter

  uses-material-design: true
This is already exists under this add below


Add these 2 lines 
  assets:
    - assert/img.jpg(img.jpg that should be given according to your filename.jpg)

after adding create one dart file in lib follow the above code

GO TO terminal->flutter pub get(all the packages will be downloaded)

flutter run/run directly by selecting that particular file.

grid view:-

import 'package:flutter/material.dart';

void main() {
  runApp(MaterialApp(
    home: Scaffold(
      appBar: AppBar(title: Text('GridView Example')),
      body: GridView.count(
        crossAxisCount: 3, 
        crossAxisSpacing: 10,
        mainAxisSpacing: 10,
        padding: EdgeInsets.all(10),
        children: List.generate(12, (index) {
          return Container(
            color: Colors.blue[(index % 9 + 1) * 100],
            child: Center(
              child: Text(
                'Item $index',
                style: TextStyle(color: Colors.white, fontSize: 16),
              ),
            ),
          );
        }),
      ),
    ),
  ));
}
